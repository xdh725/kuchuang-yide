# 知识库素材录入规范 — KUCHUANG YIDE 私有知识库

> 这是 AI 导购唯一的事实来源。**库的干净程度 = 系统的可信程度。**
> 素材录入 RAG 平台时，按本文档的标签体系打标，供检索与溯源标签（Source: …）使用。

## 目录结构（对应四类标签）

```
knowledge-base/
├── raw-materials/    原材料标签：矽钢片、磁钢、绕组线、轴承、外壳、霍尔传感器…
├── processes/        工序标签：绕线、灌胶、动平衡、CCD 二次元检测、老化测试、装配、包装…
├── applications/     场景标签：无人机、AGV、园林工具（割草机）、机器人、泵类…
├── effects/          效果标签：高效率、低温升、长寿命、低噪音、高防护等级（IP）…
└── models/           （建）型号档案：每个型号一条主记录 + 参数表
```

## 素材条目格式（每个文件/条目）

每条素材建议带元数据（RAG 平台字段或文件头 frontmatter）：

```yaml
---
id: KB-RM-001            # 唯一编号，作为溯源标签 Source ID
title: N35SH 磁钢来料检验记录
tags: [raw-material, magnet, N35SH, incoming-inspection]
type: text | image | video | spec-sheet
media: r2://kcyd-media/kb/magnet-inspection.mp4   # 关联媒体（可空）
language: en             # 客户侧答案语言，素材建议中英双语
verified: true           # 必须为 true 才允许入库
verified_by: 工程部
verified_at: 2026-09-10
---
正文：客观事实描述，不带营销形容词、不带推测。
```

## 录入规则

1. **只有可验证的客观事实才入库**。测试数据必须来自真实测试记录；参数必须来自正式规格书。
2. **一条素材讲一件事**（单点化），便于精确检索与单条溯源。
3. **禁止入库**：营销话术、未定稿参数、"大概/目标值"、竞品评论。
4. **型号清单唯一化**：所有型号以 `models/` 下档案为准。后置校验器的"官方型号列表"从此目录生成——**新增型号必须先建档案**，否则 AI 永远答不出它。
5. **材料牌号白名单**同理由 raw-materials/ 生成（磁钢牌号、矽钢片牌号、绝缘等级…）。
6. 视频素材：先按 `docs/video-encoding-guide.md` 转码上传 R2，再在条目 media 字段挂链接。
7. 更新素材 = 覆盖旧条目并更新 verified_at，**不要并存两个版本**（防止检索出新旧两份矛盾事实）。

## 与三阶段演进的配合（阶段三固化流程）

当某个复杂工况问题被 Agent 高质量回答 ≥ 3 次（后置校验记录可查）：
1. 工程部审核该回答的推演依据
2. 将审核后的结论改写为**客观事实条目**（带新的 KB 编号）入库
3. Router 规则表中该问题模式改路由到 Harness
→ 复杂问题逐渐"硬化"，从 Agent 领地迁回 Harness 领地。

## 阶段一最小入库清单（上线前必须齐）

- [ ] models/：全部在售型号档案（含参数表）
- [ ] raw-materials/：磁钢、矽钢片、绕组线、轴承、外壳 五类主材记录
- [ ] processes/：绕线、灌胶、动平衡、CCD 检测、老化测试 五道关键工序记录（各配 1 条视频）
- [ ] applications/：无人机、AGV、园林工具、机器人、泵类 五大场景记录
- [ ] effects/：高效率、低温升、长寿命、低噪音、高防护 五大效果佐证记录
