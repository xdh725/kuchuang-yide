# 需求规格说明书 — 酷创易德外贸官网

版本：v1.0 ｜ 日期：2026-09-10 ｜ 状态：已评审

## 1. 项目定位

面向**海外 B 端采购商**（外贸客户）的无刷电机（BLDC）展示与导购网站。

- 域名：独立英文域名
- **无**下单、购物车、支付、注册登录
- 首页仅两大入口，无其他导航：
  1. 🤖 **Explore Product** — AI 对话式产品介绍
  2. 🏭 **Virtual Factory Tour** — 低带宽云参观工厂
- 客户路径：**对话吃透产品 → 云参观建立信任 → 留联系方式闭环**

目标客群区域：东南亚、中东、南美、非洲等**网络波动大**的新兴市场。全站体验按弱网优化。

## 2. 功能一：AI 对话式产品介绍（逐层递进讲解）

### 2.1 定位区别

不是静态网页、不是固定视频念稿、不是被动 AI 客服。是**产品导览助手**：
有预设"讲解路线"，一问一答按需解锁，所有输出素材由工厂录入，保证 100% 准确，**不能幻觉**。

### 2.2 三层结构

**第一层：入门视频（自动播放、静音）**
- 对话页首屏加载 45–90 秒概览视频：产品是什么、核心流程、关键性能
- 编码：H.264、720p、码率 800–1200kbps
- 静音自动播放，不提供进度条拖拽（防跳片段）
- 播完后下方出现对话框及欢迎语

**第二层：知识库素材库（开放式导入内容）**
后台上传素材，按四类标签组织：
- 原材料：矽钢片、磁钢、绕组、轴承、外壳…
- 工序：绕线、灌胶、动平衡、CCD 二次元检测、老化测试…
- 场景：无人机、AGV、园林工具、机器人、泵类…
- 效果：高效率、低温升、长寿命、低噪音、高防护等级…

**第三层：兜底出口（引导询盘）**
对话末尾固定引导句 + 极简表单（名字、公司、邮箱/WhatsApp，**仅三栏**）。

### 2.3 对话节奏示例（客户视角）

```
客户: What's your motor used for?
AI:   Our motors are widely used in drones, robotic lawn mowers and
      logistics AGV. Would you like me to introduce drone application first?
客户: Yes.
AI:   [调出无人机实测短视频] + 文字：高海拔、大动态载荷下的效率表现…
客户: （追问磁钢材质）
AI:   [调出磁钢素材]…
客户: （问动平衡）
AI:   [调出车间动平衡工序素材]…
```

B 端采购商各取所需：有人关心转速、有人关心耐温、有人关心寿命。

### 2.4 关键约束（防幻觉，最高优先级）

- **禁止大模型自由编造参数**。所有回答必须优先调取已上传的文字、图片、短视频片段
- AI 只做串联、转述，不能生成未录入的数据 → **RAG 模式，非通用聊天**
- 禁止做成"通用 AI 聊天机器人"——AI 吹牛、报错参数、编造测试数据在外贸里会造成索赔
- 安全兜底话术：*"This detail is best answered by our engineer. Please leave your contact info."*

### 2.5 部署要求

- 不自建大模型服务器：网页嵌入 RAG 知识库 API + 聊天 UI
- 前端自己写；知识库托管（火山方舟 / OpenAI RAG）
- 素材存海外对象存储（S3 或 Cloudflare R2），避免国内服务器海外访问卡顿

## 3. 功能二：低带宽"云参观工厂"

### 3.1 核心诉求

连线视频：**清晰度不用高，优先保证"连得上、不断流"**。1080p 在目标市场极易卡死导致客户流失。

### 3.2 三套方案（按推荐优先级）

**方案 A：预录分段 + "伪直播"（首推，性价比最高）**
- 工厂路线拆固定镜头：来料仓库、绕线车间、CCD 视觉检测工位、老化房、打包区
- 每机位录 720p、500–700kbps 视频，网页按钮点播
- 优势：零直播服务器成本、无限次播放、完全适配最差网络、画面可控
- 升级：每日更新"Today's workshop snapshot"板块营造新鲜感
- 90% 的 B 端客户足够满意——目标是验证"真工厂非贸易商"

**方案 B：WebRTC 低码实时推流（真·实时可选入口）**
- 640×360（不超 720p）、H.264（不用 H.265）、350–550kbps、15fps
- 动态码率自适应（差时降至 200kbps，宁糊不断流）
- 音频默认关闭（按钮开启），链路：车间摄像头 → 边缘主机 → 海外边缘节点 → 浏览器
- **禁止国内服务器直接对外推流**（国际出口抖动丢包严重）
- 成熟选择：Cloudflare Stream / Ant Media Server

**方案 C：按需预约人工视频连线（高信任、高转化补充）**
- "Book a LIVE guided tour" 预约按钮：填时间、时区、WhatsApp
- 业务员通过 Zoom/Teams/WhatsApp 视频带逛车间答疑
- 补充功能，不作为默认页面

**默认组合**：方案 A 随时看 → 不够则引导预约方案 C。
**禁止**：默认 7×24 无人值守实时直播（成本高 + 画面泄露风险）。

## 4. 页面架构（极简，共 4 页）

| # | 页面 | 内容 |
|---|------|------|
| 1 | 首页 `index.html` | 大标题 + 两大卡片按钮 + 页脚（邮箱/WhatsApp/地址），**没有别的导航栏** |
| 2 | `product-explorer.html` | 顶部自动播放概览短视频 + 聊天窗口 + 右下角询盘按钮 |
| 3 | `virtual-tour.html` | 场景按钮 + 低码视频 + 底部预约人工连线引导 |
| 4 | `thank-you.html` | "Thank you! Our engineer will contact you shortly." |

## 5. 服务器与 CDN（重中之重）

- 所有静态资源、视频、图片、知识库附件 → **海外节点**：Cloudflare R2 + Cloudflare CDN
- **禁止**阿里云国内存储直接对外服务
- 网站为纯静态（HTML+JS），部署 Cloudflare Pages，零服务器租金
- 仅 RAG 问答部分调用 API

## 6. 落地优先级

**阶段 1（第一版上线）**
1. 静态首页
2. 产品介绍短视频按标准参数压缩上传 CDN
3. RAG 知识库搭建、导入全部电机资料/场景案例、对话页上线
4. 工厂各工位参观视频低码转码、预录版云参观上线
→ 到此两大核心需求全部落地，可对外推广

**阶段 2（迭代升级）**
- 预约人工导览表单
- 选择性上线 WebRTC 实时流（可选入口，非默认）
- 按高频问题持续扩充知识库

## 7. 与工厂内部数字化的关系

内部 AI 视觉系统 + ERP 抓生产过程；网站把"经过筛选、包装过的生产证据"交付给客户。海外采购商难实地验厂 → 等于开放数字化工厂的一小扇窗口，差异化卖点。
