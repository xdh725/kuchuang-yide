## 交互注记（给设计/开发）

1. 视频缺失 = 优雅降级：概览视频隐藏整块；工位视频替换为引导文案——绝不出现黑屏/报错
2. 聊天兜底消息必带「Leave contact」内嵌按钮，把兜底变成转化动作
3. 语言切换即时生效不刷新；云参观切语言不重载视频
4. 移动端：header-note 隐藏、卡片单列、FAB 内缩、聊天消息气泡加宽至 92%
5. 工位按钮键盘可达（原生 button）；焦点环全局可见
