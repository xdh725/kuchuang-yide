# UX 需求分析 — 酷创易德外贸官网

版本：v1.0 ｜ 日期：2026-09-10 ｜ 阶段：原型设计前置输入（流程：需求分析 → 原型 → 页面设计 → 设计规范 → 开发）

## 1. 用户画像（Persona）

### P1 采购工程师 Steve（主要，60%）
- 角色：海外设备厂/贸易商的 sourcing engineer，技术背景
- 目标：验证供应商真实性（真工厂非贸易商）；拿到可核实的电机参数做选型
- 行为：先看产品页问参数 → 不放心就要求看产线 → 留邮箱要 datasheet
- 痛点：同行网站堆 PPT 图片、参数不可信；AI 客服胡编参数；弱网打开就卡
- 期望：答案带来源、看图能选型、视频能播

### P2 采购决策人 Ahmed（35%）
- 角色：中东/东南亚工厂主或采购负责人，非技术细节导向
- 目标：快速判断"这家靠不靠谱、能不能稳定供货"
- 行为：扫一眼首页 → 直接点 Factory Tour 看车间 → 看到真实产线就留 WhatsApp
- 痛点：英文阅读一般（需要清晰视觉传达，不依赖长文本）；网络差
- 期望：视频一键播、页面少、路径短

### P3 已合作客户 Li（5%）
- 目标：快速转发网站给同事/上级做二次确认
- 期望：URL 干净、页面可直达、加载快

## 2. 关键用户旅程（Journey）

```
J1 选型之旅（P1）
落地首页 → (2s内理解定位) → 点 Explore Product → 看概览视频(≤90s)
→ 提问参数(2-4轮, 每轮≤5s响应) → 追问工序/材料(看来源标签建立信任)
→ 点 Inquiry 留联系方式 → Thank-you
成功指标：3+ 轮对话、询盘提交

J2 验厂之旅（P2）
落地首页 → 点 Virtual Factory Tour → 点 2-3 个工位视频(每个都能播)
→ 看到 CCD 检测/老化房(信任峰值) → 预约 Live Tour 或留 WhatsApp
成功指标：视频播放≥2段、预约点击

J3 兜底之旅（任何 P）
提问 → 库里没有 → 兜底话术 → 留联系方式
成功指标：兜底→询盘转化率（兜底是信任动作而非失败）
```

## 3. 信息架构（4 页，不增不减）

```
index（定位+双入口）
├─ product-explorer（概览视频 + 对话 + 询盘）
├─ virtual-tour（5 工位点播 + 今日实拍 + 预约 Live）
└─ thank-you（确认页）
全局：语言切换(EN/中/…)、询盘 FAB（product-explorer/virtual-tour 页常驻）
```

## 4. 体验原则（设计判断依据，按优先级排序）

1. **可信 > 好看**：每个 AI 回答带来源标签；视频不追求高清追求"能播"；不夸大文案
2. **弱网是一等公民**：首屏 LCP 目标 < 2.5s（3G 模拟）；视频按需加载；无 webfont/大图
3. **路径极短**：任何页面 ≤ 1 次交互可达询盘；表单仅 3 栏
4. **信任的视觉语言**：精密工业风（深色、工程网格、数据感排版）传递"制造能力"，而非消费品牌的花哨
5. **国际化默认**：英文为主语言；中文完整；预留 es/ar（阿语注意 RTL 预留——布局避免强制左右）

## 5. 关键页面 UX 要求（原型验收标准）

| 页面 | 必须满足 |
|------|----------|
| index | 3s 内看懂"电机厂+两个入口"；两大卡片视觉权重均衡；页脚联系完整 |
| product-explorer | 视频静音自动播（无视频时优雅隐藏不留白）；聊天区 ≥ 60vh；来源标签样式清晰；图附传入口可发现 |
| virtual-tour | 5 工位常显可点；当前选中态明确；视频缺失时引导留资不报错；预约 CTA 在首屏内可见 |
| thank-you | 单屏确认 + 返回首页；无死胡同 |

## 6. 无障碍与合规

- 对比度：正文 ≥ 4.5:1，大标题 ≥ 3:1（WCAG AA）
- 焦点可见（focus-visible 全局样式）
- 表单 label 关联、按钮语义化
- prefers-reduced-motion 尊重
- 语言切换后 `<html lang>` 同步（已实现）

## 7. 度量（上线后埋点，阶段二）

- 对话轮次分布、兜底触发率、视频播放完成率、询盘转化率、语言切换分布
- 兜底触发率 > 40% → 知识库缺素材，补库而非改文案
