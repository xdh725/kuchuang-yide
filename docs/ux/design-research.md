# 设计调研 — 学习市面顶级网站（首页 Hero 与卡片模式）

日期：2026-09-10 ｜ 输入到：首页重设计 ｜ 样本：Linear / Stripe / Vercel（+ 工业站 Siemens/ABB 通用范式）

## 提炼出的共性设计语言

### 1. Hero：一句话价值主张 + 双按钮，无装饰元素
- **Linear**：巨型 H1（"The product development system for teams and agents"）+ 一行副标 + 两个按钮（Start building / Book demo）。eyebrow 用小字胶囊。
- **Stripe**：H1 + 副标 + 双 CTA，下方紧跟**数据条**（135+ currencies / $1.9T volume / 99.999% uptime）——大数字用等宽/加重排版，**这是 B2B 信任的核心手法**。
- **Vercel**：H1 + 三行带图标的要点 + 双按钮（Deploy now 主 / Talk to sales 次）。
- 结论：**优秀站的 hero 都极克制**——没有多余的 chip/图标，只有 文案层级 + 按钮 + 数据证明。

### 2. 数据证明条（取代我们的"信任条"）
Stripe 模式：`大数字 + 说明` 的横排（4 格），数字大字号加粗、说明小字灰色。
我们可用（全部来自已验证事实，不编参数）：
- 5 大应用场景（无人机/AGV/园林/机器人/泵）
- 5 道关键工序全检（绕线/灌胶/动平衡/CCD/老化）
- 1 个工作日工程师响应
- EN 双语站 / 弱网可访问
→ 前两条可做成数字型（5 / 5 / 1 / 2），具体产能数字待工厂确认后补。

### 3. 双入口卡片：Linear/Vercel 的做法
- **无图标占角**。用**大标题 + 短正文 + 单个箭头链接**，或标题上方一个**小节 eyebrow**（如 "01 / Explore"）。
- 卡片间用编号或 eyebrow 制造节奏（Vercel: "01 02 03" 编号小字在角落）。
- hover：背景轻微提亮 + 边框变色，**不做大位移**。
- 结论：印证用户直觉——去掉角标图标是对的；市面顶级站用**编号 eyebrow + 大标题**建立高级感。

### 4. 文案纪律
- 每张卡正文 ≤ 2 行；标题不堆形容词。
- 副标把两个入口的价值说清楚，H1 说定位。
- **一屏一个主行动**：hero 双按钮里 primary 只有一个。
